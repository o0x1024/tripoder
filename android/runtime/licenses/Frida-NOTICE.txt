Tripoder Runtime embeds unmodified Frida Gadget 17.23.3 and bundles
frida-java-bridge 7.0.13, modified by Tripoder on 2026-10-14.

The local modification adds an explicitly selected method-only class model.
It is reproduced from hash-pinned upstream files by android/scripts/runtime_bridge.py;
the build receipt records original and generated source SHA-256 values.

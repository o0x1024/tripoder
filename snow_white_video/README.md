# 白雪公主与七个小矮人 · 绘本动画短片

一部约 **3 分钟** 的中文有声绘本动画，全部素材在本地程序化生成，无外部素材依赖。

## 成片

- `out/snow_white.mp4` — 1920×1080 / 30fps / H.264 High + AAC 立体声，**3 分 05 秒（185.7s，5570 帧）**，82.7 MB
- `storyboard.html` — 分镜一览（图 + 旁白 + 时间码），可直接在浏览器/预览器打开
- `out/contact_sheet.jpg` — 14 个镜头联系表
- `out/poster.jpg` — 片头海报
- `frames/scene_01_title.png` … `frames/scene_14_endcard.png` — 14 张 2560×1440 分镜插画

校验结果（`python3 verify.py`）：视频 1920×1080/30fps/5570 帧，音频 44.1kHz 立体声 193kb/s，
解码峰值 0.818（无削波），12 段旁白期间字幕覆盖率 100%，末镜结束时间与总长完全吻合。

## 制作管线

```
story.py      分镜与旁白文案（14 场）
art.py        PIL 程序化绘制：天空渐变、山脊、松林、木屋、城堡、人物、光晕、暗角、纸感噪点
render_all.py 4 进程并行渲染 14 张 2560×1440 插画（2 倍超采样后降采样）
tts.py        macOS say（Tingting 中文女声）逐句合成 → 去首尾静音 → 拼接 → 生成 timeline.json
film.py       把相邻镜头按 0.9s 交叉溶接重排时间轴
score.py      numpy 合成八音盒配乐（Am–F–C–G 琶音 + 长音铺底 + 多抽头混响），按人声自动 duck，混音输出 final.wav
compose.py    逐帧：Ken Burns 运镜（推近/左右横移）→ 溶接 → 底部渐隐 + 中文字幕 → 光尘粒子 → 首尾黑场，raw RGB 直接灌入 ffmpeg
```

运行：

```bash
python3 render_all.py      # 生成 14 张插画
python3 tts.py             # 生成旁白与时间轴
python3 score.py           # 生成配乐与最终混音
python3 compose.py         # 合成 1080p 视频 -> out/snow_white.mp4
```

依赖：macOS（`say` 与 `Songti.ttc` 字体）、Python3 + Pillow + numpy、ffmpeg（libx264）。

## 技术要点

- **插画不是贴图**：所有场景由坐标、渐变与图层合成画出来，2× 超采样保证边缘平滑。
- **时序由配音驱动**：先测每句旁白的真实时长，再决定镜头长度（最短 6 秒），字幕与旁白严格对齐。
- **交叉溶接**：相邻镜头重叠 0.9 秒，用时长短于 1 秒的 `Image.blend` 无缝过渡，避免硬切。
- **人声优先的混音**：旁白出现时把配乐压到 45%，并做 0.35 秒平滑包络，避免突跳。
- **字幕安全区**：底部 20% 渐隐遮罩 + 行距自动折行，深色调场景也清晰可读。
